# えまちゃんの算数ゲーム

1〜10 までのたしざん（100 通り）をフラッシュカード形式で解く、タブレット向けのゲームです。
インストール不要・1 枚の HTML（`index.html`）だけで動き、記録は端末のブラウザ内に保存されます。

## 遊び方

- **100もん チャレンジ** … 1〜10 の全組み合わせ 100 問をシャッフルして出題。10 分以内にクリアでトロフィー。
- **にがて チャレンジ** … 間違えた問題・時間がかかった問題を 2 回ずつ混ぜて出題（足りない分は 7・8 の問題で補う）。
- **7と8 とっくん** … 7 か 8 を含む 36 問だけ。

答えは画面テンキーで入力（PC ならキーボードの数字・Enter・Backspace も可）。
2 桁入力すると自動で判定、1 桁は「OK」で判定。間違えると正解を表示して「つぎへ」で進みます。
1 問ごとの時間は表示しません。全体の経過時間だけ右上に小さく出ます。

ペット「アクア」は正解数でレベルアップし、見た目が変わります（ほっぺ → 葉っぱ → リボン → 王冠 …）。

## おうちのひと 画面

ホーム下の「おうちのひと へ」から開けます。

- 問題別ヒートマップ（平均時間 / まちがい率 / 回数）
- セッション履歴（モード・正解数・時間・にがて問題）
- 設定：ペットの名前、「遅い」とみなす秒数、にがてチャレンジの問題数、0 を含めるか、効果音
- すべての記録の削除

## 動かし方

- ローカル：`index.html` をブラウザで開くだけ。
- Android タブレット：Web に公開した URL を Chrome で開き、「ホーム画面に追加」すると全画面アプリとして使えます（`manifest.json` 同梱）。
